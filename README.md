# GestorBibliotecaJAVA
Parcial 1 de Interfaz Gráfica, IES. Aplicación de consola con Java.

## Instrucciones de ejecución
### Opción con Netbeans
1. Descargar o clonar el proyecto. 
2. En Netbeans, File/Open project/ y seleccionar el proyecto "Parcial-Markoja" en la carpeta donde fue descargado.
3.  Click en "Open project".
4. Luego de haberse cargado correctamente, click en "Run" o F6, para correr el proyecto en la terminal de Netbeans.
